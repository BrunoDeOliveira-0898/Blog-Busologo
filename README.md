# Blog com CRUD - Axios, React.js e React Router DOM

## 📋 Sobre o Projeto

Projeto de blog desenvolvido com React.js, integrando operações CRUD completas através do Axios para comunicação com API e React Router DOM para navegação entre páginas.

## 🛠️ Tecnologias Utilizadas

- **React.js** - Biblioteca para construção de interfaces
- **React Router DOM** - Roteamento de páginas
- **Axios** - Cliente HTTP para requisições
- **JavaScript ES6+** - Linguagem principal
- **CSS** - Estilização de componentes

## ✨ Funcionalidades

### CRUD Completo

- **Create** - Criar novos posts
- **Read** - Listar e visualizar posts
- **Update** - Editar posts existentes
- **Delete** - Remover posts

### Navegação

- Roteamento entre páginas com React Router DOM
- Links dinâmicos para posts individuais
- Navegação intuitiva

### Requisições HTTP

- Integração com API via Axios
- GET, POST, PUT e DELETE requests
- Tratamento de erros e respostas
